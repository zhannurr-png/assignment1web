# Web Technologies Assignment

## Description

This project contains my Web Technologies assignment and it includes four tasks created using HTML and CSS.

## Tasks

### Task 1 - Personal Webpage
A personal webpage with:
- Profile information
- Profile image
- Hobbies
- Goals
- Useful links

### Task 2 - Movie Club
A movie club webpage created using HTML div elements and CSS positioning.
It includes:
- Header
- Navigation bar
- Sidebar
- Movie descriptions
- Footer

### Task 3 - Tribute Page
A tribute page dedicated to Jake Gyllenhaal.
It includes:
- Biography
- Important moments
- Major contributions
- Useful links
- Image

### Task 4 - Tables and Forms
A webpage containing:
- Student grades table
- Alternate row colors
- Highlighted row
- Colspan
- Feedback form

## Technologies

- HTML5
- CSS3

## How to Run

Open `task2.html` in a web browser and use the navigation bar to access the other tasks.
